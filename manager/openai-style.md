## 概述
OpenAI 主页是"内容即设计"的极简主义：纯白画布、近黑文字、几乎无彩色。靠留白、排版层级与发丝边框建立秩序，而非阴影或色块。按钮为纯黑药丸，交互克制（仅轻微底色/位移变化）。整体冷静、理性、产品感强。

## 颜色
### 品牌与强调色
- 主色 = 近黑 `#0d0d0d`（按钮、强调）
- 无高饱和品牌色；链接以下划线/底色表达，而非彩色
### 表面色
- 画布 `#ffffff`
- 卡片 `#ffffff`（靠边框区分）/ 次级面 `#f7f7f8`
- 反转面（深色区块）`#0d0d0d`
### 文字色
- 主文字 `#0d0d0d`
- 次文字 `#5d5d66`
- 占位/禁用 `#9a9aa2`
### 语义色
- 成功 `#16794c`（克制使用）/ 错误 `#d11507`
### 渐变 / 特殊效果
- 基本不用渐变；偶见极淡灰阶过渡

## 排版
### 字体家族
- 正文/标题：`"OpenAI Sans", ui-sans-serif, -apple-system, "Segoe UI", "Helvetica Neue", Inter, Arial, sans-serif`
- 代码/标签：`ui-monospace, "SF Mono", Menlo, monospace`
### 层级表
| Token | 字号 | 字重 | 行高 | 字距 | 用途 |
|-------|------|------|------|------|------|
| display | 48–56px | 500 | 1.05 | -0.03em | 首屏大标题 |
| h2 | 28–32px | 500 | 1.1 | -0.02em | 区块标题 |
| card-title | 17px | 600 | 1.3 | -0.01em | 卡片标题 |
| body | 16px | 400 | 1.5 | 0 | 正文 |
| meta | 13px | 400 | 1.4 | 0 | 辅助文字 |
| label | 13px | 500 | 1 | 0 | 标签/按钮 |
### 原则
- 标题用 **中等字重 + 负字距**，不堆砌粗体
- 句子大小写，不全大写堆砌
- 次要信息一律降灰，不靠彩色区分

## 布局与间距
### 间距系统
8px 基准：xs 4 / sm 8 / md 16 / lg 24 / xl 40 / 2xl 64
### 网格/容器
- 最大内容宽度 ~1100px，居中
- 卡片网格自适应 `minmax(300px, 1fr)`
### 留白习惯
- 区块上下 48–80px；卡片内边距 20–24px；首屏极阔留白

## 圆角与形状
### 圆角等级
| Token | 值 | 用途 |
|-------|----|------|
| sm | 8px | 输入/小元素 |
| md | 16px | 卡片 |
| pill | 999px | 按钮、徽章 |
### 特殊形状
- 按钮一律药丸（全圆角）

## 阴影与深度
- 几乎不用投影；用 **1px 发丝边框** `#ececec` 建立层次
- 仅在 hover 时给极淡阴影 `0 6px 20px rgba(0,0,0,.06)` + 轻微上移

## 组件样式
- **主按钮**：黑底 `#0d0d0d` / 白字 / 药丸 / padding 11px 22px / hover `#383838`
- **次按钮**：白底 / 1px 边框 `#d8d8dc` / 黑字 / 药丸 / hover 底 `#f7f7f8`
- **卡片**：白底 / 1px 边框 `#ececec` / 圆角 16px / 无投影 / hover 轻阴影+上移
- **导航栏**：白底毛玻璃 / 底部 1px 发丝线 / 极简
- **输入框**：白底 / 1px 边框 / 圆角 8px / focus 边框转近黑
- **徽章**：浅灰底 `#f0f0f2` / 次文字色 / 药丸 / 小字

## 注意事项（Do's and Don'ts）
- **应做**：黑白为主、发丝边框、药丸按钮、大留白、标题负字距、交互克制
- **不应做**：重投影、高饱和彩色、彩色渐变、到处粗体、强烈悬停动效
